# 🕸️ Web Scraping - E-commerce Product Data Extractor

This project is a **Web Scraping Program** developed as part of **ProDigy InfoTech Internship - Task 05**.

---

## 📌 Project Description

The program extracts product information such as:

- 🛍️ Product Names
- 💰 Prices
- ⭐ Ratings

from an e-commerce website and stores the collected data in a structured format like a **CSV file**.

---

## 🚀 Features

- Extracts product details from a website
- Collects name, price, and rating information
- Stores data in CSV format
- Easy to modify for different websites
- Simple and readable code

---

## 🌐 Website Used

You can use any website for scraping. Recommended for beginners:

- http://books.toscrape.com (safe for practice)
- https://quotes.toscrape.com

---

## 🧠 How It Works

1. Sends a request to the website
2. Parses HTML content using a parser
3. Extracts required data fields
4. Stores the extracted data into a CSV file

---

## 🛠️ Technologies Used

- Python
- requests (for HTTP requests)
- BeautifulSoup (for parsing HTML)
- pandas / csv module (for storing data)
